Doc: the Platform Owner adds, edits, merges and retires categories without a release (AI-08), and each category carries its own SLA (Category.slaHours). Lists use short names (full doc names: Technical issue / bug, How-to / usage question, New use case / idea, Data, privacy and compliance, Training and enablement, Internal communication, Spam / irrelevant, Other / needs review). SLA hours are sample values; the doc says to validate the category list against 3 months of real mail. AI-09 (Could): the AI can propose new categories and the Owner approves them.
